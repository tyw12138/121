# 书伴 - AI 小说阅读搭档

## 项目简介

书伴是一款 Android 端的 AI 小说阅读助手，以悬浮窗形式叠加在现有阅读 App（起点、晋江、微信读书等）之上，提供剧情回顾、人物关系梳理、AI 角色对话、个性化推荐等功能。用户无需切换应用，即可享受 AI 增强的阅读体验。

## 核心功能

### 1. AI 角色对话
与小说中的角色进行沉浸式对话，探讨剧情走向、角色动机，获得独特的互动阅读体验。

### 2. 剧情回顾与人物关系梳理
一键生成剧情摘要、时间线和人物关系图谱，快速回顾前情，理清复杂的人物关系网络。

### 3. 个性化推荐
基于阅读历史和偏好分析，推荐真正契合口味的新书，告别千篇一律的榜单推荐。

## 技术栈

- **平台**: Android (Kotlin)
- **核心功能**: 悬浮窗服务、无障碍服务
- **AI 引擎**: 大模型 API (当前为 Mock 实现)
- **数据存储**: Room 数据库

## MVP Demo 功能

当前版本实现了以下核心功能：

1. **悬浮窗服务**: 可在其他应用上层显示的悬浮窗
2. **文本输入**: 支持粘贴小说文本进行分析
3. **AI 对话**: 模拟 AI 对话功能
4. **剧情摘要**: 自动生成剧情摘要
5. **人物关系**: 展示人物关系图谱

## 使用说明

1. 安装应用后，点击"开启服务"按钮
2. 授予悬浮窗权限
3. 在任意阅读 App 中，悬浮窗将显示在屏幕上
4. 粘贴小说文本，使用各项功能
